# Python Beginner Projects

My first Python projects, built while learning programming fundamentals and building a strong foundation in computer science. 

## 🚀 Projects Included

*   **Dynamic Quiz App:** A command-line trivia game that dynamically reads questions, options, and answers from an external `questions.csv` database.
*   **Contact Book:** An application to efficiently store, view, and manage user contacts.
*   **Unit Converter:** A mathematical tool to convert various units of measurement.
*   **Rock, Paper, Scissors:** A classic game utilizing Python's `random` module and logic handling.
*   **Number Guessing Game:** An interactive game utilizing while loops and conditional logic.
*   **Calculator:** A fully functional calculator for handling basic arithmetic operations.

## 🧠 Core Skills Demonstrated

*   **File Handling (I/O):** Reading, processing, and formatting external data files using Python's `csv` module.
*   **Data Structures:** Advanced manipulation of lists and nested dictionaries.
*   **Control Flow:** Designing robust game loops using `for` loops, `while` loops, and `if/else` conditionals.
*   **Version Control:** Managing multi-file project dependencies via GitHub.
