# Python Beginner Projects

My first Python projects, built while learning programming fundamentals and building a strong foundation in computer science.

## 🚀 Projects Included

*   **Tic-Tac-Toe:** A command-line two-player game using 2D-to-1D list indexing for the board and win-condition checking across 8 possible combinations.
*   **Dynamic Quiz App:** A command-line trivia game that dynamically reads questions, options, and answers from an external `questions.csv` database.
*   **Contact Book:** An application to efficiently store, view, and manage user contacts, with persistent storage to a text file.
*   **Number Guessing Game:** An interactive game utilizing while loops, attempt tracking, and conditional logic.
*   **Rock, Paper, Scissors:** A classic game utilizing Python's `random` module and logic handling.
*   **Unit Converter:** A mathematical tool to convert various units of measurement.
*   **Calculator:** A fully functional calculator for handling basic arithmetic operations.

## 🧠 Core Skills Demonstrated

*   **File Handling (I/O):** Reading, processing, and formatting external data files using Python's `csv` module and plain text files.
*   **Data Structures:** Manipulation of lists, nested dictionaries, and 1D-to-2D grid mapping.
*   **Control Flow:** Designing robust game loops using `for` loops, `while` loops, and `if/else` conditionals.
*   **Debugging:** Found and fixed a real logic bug in Tic-Tac-Toe, where checking for a draw before checking for a win caused a winning final move to be misreported as a draw — reordering the checks fixed it.
*   **Version Control:** Managing multi-file project dependencies via Git and GitHub.
